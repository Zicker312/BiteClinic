# Инструкция по запуску проекта

Для запуска сайта и тестирования его функционала выполните следующие действия:

## Требования
- Установленный [OpenServer](https://ospanel.io/) (или другой локальный веб-сервер)

## Основные шаги
1. Запустите OpenServer
   - Активируйте панель управления OpenServer
   - Нажмите кнопку "Запустить"

2. Откройте папку проекта
   - Перейдите в директорию с файлами сайта
   - Найдите файл index.html

3. Запустите сайт
   - Двойной клик по index.html для открытия в браузере по умолчанию
   - Или перетащите файл в окно предпочитаемого браузера

## Альтернативные способы
- Можно открыть сайт через адресную строку OpenServer (если проект размещен в директории domains)
- Для разработчиков: можно использовать Live Server в VS Code
